# כללי דפי ה-HTML (כל דפי הלקוחות)

## ייחוס וואטסאפ
- **כל קישור וואטסאפ נושא "(הגעתי מהאתר)"** או נפתח ב-"היי, הגעתי מהאתר של STEPS". ההודעה הראשונה היא מה שמזהה את המקור ב-Arbox — בלעדיה הליד נראה כמו כל "הודעה בוואטסאפ".
- חריגים במכוון (בלי סימן): קישור מדיניות הביטולים, `accessibility.html`, `privacy.html`.
- **לא לשכפל `?text=`.** `var WA` ב-`index.html` נשאר קישור חשוף; הקריאות שמרכיבות לינק דינמית מוסיפות `?text=` בעצמן. הסימן חי בתוך המחרוזות, לא בבסיס (באג 8/8/26: `?text=…?text=…` שבר את כפתור הכשל).
- מספר: 972527927575.

## אמת
- אין "נותרו N מקומות" — Arbox לא מחזיר תפוסה.
- אין מערכת שעות מזויפת או fallback קשיח: כשל API → "מערכת השעות נטענת. לקביעת שיעור — דברי איתנו בוואטסאפ"; יום ריק → "אין שיעורים ביום זה".
- אין המצאת פרטים (מחירים, גילאים, גודל קבוצה, שמות). לא מאושר → מפנים לצוות. עדויות = ביקורות גוגל אמיתיות בלבד. פרטי הנוער המאושרים — ב-CLAUDE.md.

- כפתור ♿ + מודאל הצהרת נגישות, skip link ל-`#top`, ARIA landmarks, alt לכל תמונה, `role="img"` לדירוגי כוכבים, ניווט מקלדת.
- WCAG AA: 0 כשלי ניגודיות (נמדד בדפדפן ב-1280 וב-390). טקסט לבן על צהוב אסור.
- עברית, **לשון נקבה** ללקוחות.

- GA4 / Meta Pixel נטענים רק אחרי הסכמה לעוגיות. גופנים באירוח עצמי — לא Google Fonts.
