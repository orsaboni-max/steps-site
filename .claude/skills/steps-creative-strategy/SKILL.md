# STEPS Creative Strategy — מנוע הרעיונות

הסקיל שמחבר את כל מערך הקריאייטיב לגיוס לקוחות. סוגר את הלולאה "לשכפל מה שעובד".

## קודם תקרא (חובה)
1. `marketing/MARKETING-STRATEGY.md` — הצפון: קהל, הצעה, ערוץ מנצח (וואטסאפ), KPIs.
2. `marketing/research/my-winners.md` — מה עובד אצלי (מ-Meta, מתעדכן).
3. `marketing/research/competitor-research.md` — מתחרים בארץ.
4. `marketing/research/inspiration-abroad.md` — השראה מחו"ל + עקרונות 2026.
5. `marketing/brand/brand-dna.md` — קול המותג (חובה לכל קופי).

## הלולאה (איך מייצרים רעיון)
1. **קלט:** מנצחים שלי + דפוסי מתחרים + השראה חו"ל.
2. **רעיון:** קונספט חדש = הוק + סצנה + הצעה + "למה יעבוד" (קישור לדפוס מנצח).
3. **הפקה:** קופי → סקיל `steps-ad-copy`. ויזואל → `steps-studio-visuals`. ריל → `steps-reel-pipeline` (Higgsfield, 852 קרדיטים).
4. **השקה:** `steps-campaign-builder` (PAUSED עד go של אור).
5. **מדידה:** `steps-performance-analyst` → מנצחים חוזרים ל-`my-winners.md`.

## עקרונות קריאייטיב (מאומתים מהנתונים)
- **וידאו/רילז מנצח אצל STEPS** (CTR עד 3.18% מול 1.5% בנצ'מארק). להעדיף וידאו.
- **UGC = פורמט #1 בעולם** (פי 4 CTR). מתאמנת אמיתית: בעיה→גילוי→תוצאה.
- **3 שניות ראשונות מכריעות** — הוק חזותי + כתובית תוך 2ש'.
- **וואטסאפ = CTA מנצח** (26% מההמרות). כל גיוס → CTWA.
- **<15ש' + כתוביות + אודיו טרנדי** = פי 3-5 reach.

## הדשבורד
`marketing/creative/idea-dashboard.html` — המרכז. 4 קטעים: מנצחים שלי · מתחרים בארץ · השראה חו"ל · תור 3 רעיונות. מתעדכן שבועי (שגרת `steps-creative-ideas-weekly`, שני 09:00).

שליפת top ads: `ads_get_ad_entities` (account 9773300439396945), level=ad, sort=ctr_descending, date_preset=last_90d. לעדכן את `my-winners.md` + הדשבורד.
