# Code Mastery — שיטת העבודה

גרסה 3 (7/9/26), מותאמת לפייבל 5.1. הקובץ מתאר מטרה ומגבלות, לא צעדים: את הצעדים המודל
מבצע לבד, וחוקים סותרים רק גורמים לו לבחור באקראי. פרטי כל פרויקט (פקודות, deploy, סביבה)
חיים ב-CLAUDE.md של אותו פרויקט, לא כאן.

## שלושה עקרונות

**פשטות.** השינוי הקטן ביותר שעובד. מחיקת שורות עדיפה על הוספה, ופתרון של 5 שורות על 50,
כי כל שורה נוספת היא משהו שמישהו יצטרך להבין ב-3 בלילה.

**סיבת שורש.** לפני תיקון מבינים למה זה נשבר. `try/except` שמסתיר בעיה או `# TODO: fix later`
מזיזים את הבאג ללקוחה הבאה במקום לסגור אותו.

**נגיעה מינימלית.** "תקן את הבאג ב-router.py" = לגעת ב-router.py. בעיה אחרת שרואים בדרך
מציינים ולא מתקנים בשקט, כך ה-diff נשאר קריא ואפשר לבדוק אותו.

## הלולאה: חקור → תכנן → בצע → אמת

**חקור.** קוראים את הקבצים שהשינוי נוגע בהם, ולכל שדה או מצב שהקוד החדש כותב אליו שואלים:
מי עוד קורא או כותב אותו? רוב הבאגים אצלנו היו בתפר עם מנגנון קיים, לא בקוד החדש.

**תכנן — כלל המשפט האחד.** משימה שאפשר לתאר במשפט אחד הולכת ישר לקוד. משימה שלא,
תוכנית קצרה קודם: אילו קבצים, באיזה סדר, ואיך מאמתים. על דבר הפיך לא מחכים לאישור:
שורה אחת מה עושים, וממשיכים. עוצרים רק במחיקה שלא חוזרת או בהודעה יוצאת ללקוחה אמיתית
(סעיף 4 ב-CLAUDE.md הגלובלי).

**בצע.** בחתיכות שכל אחת נבדקת בנפרד, בסגנון הקוד שסביבה. נשבר משהו, מתקנים לפני שממשיכים,
כי בעיה פתוחה מזהמת את כל מה שנבנה מעליה.

**אמת.** לכל שינוי יש ראיה שאפשר להראות לאור: טסט, screenshot, פלט. "מוכן" נאמר רק אחרי
שהתוצאה נראתה במציאות מקצה לקצה (סעיף 5.1), לא על סמך טסטים ירוקים או 200 מה-API.

## פעמיים → סקיל

משימה שחזרה פעמיים הופכת לסקיל (נטען לפי הקשר, עם description עשיר בטריגרים) או
ל-slash command (`.claude/commands/`, מופעל ידנית). בפעם השלישית מפעילים אותו במקום
לחזור על הפרומט.

## מה שייך לאיפה

| מקום | מה נכנס | למה |
|---|---|---|
| `CLAUDE.md` | עובדות שלא מנחשים: פקודות, מבנה, gotchas, החוזה עם אור | נטען כל שיחה, לכן קצר (עד 200 שורות) |
| `.claude/rules/` | כללים לפי נתיב (`api/**`, `*.html`) | נטענים רק כשנוגעים בקבצים האלה |
| `settings.json` | הרשאות, מודל, attribution, env | אכיפה דטרמיניסטית; הוראה שאפשר לאכוף כאן לא נכתבת כטקסט |
| hooks | בדיקה שרצה באמת (Stop gate שמריץ טסטים), לא echo | המערכת מריצה, לא המודל |
| skills | workflow חוזר, SKILL.md קצר + `references/` לפירוט | נטען לפי צורך |
