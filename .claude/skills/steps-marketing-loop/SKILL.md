# STEPS — לולאת השיווק הסגורה (רנבוק)

> מטרה: כל ליד נכנס מתויג, נענה מהר, וכשהופך ללקוחה — מטא לומדת. **6 תחנות.**
> מצב-אמת חי תמיד ב-`marketing/STATUS.md`. כאן = איך הלולאה עובדת + ההחלטות הנעולות.

## 6 התחנות
| # | תחנה | איך | מצב (4/6) |
|---|------|-----|-----------|
| 1 | מודעה (קמפיין מתויג) | Meta, קריאייטיב `steps-image-gen` + קופי `steps-ad-copy` | לכל קמפיין |
| 2 | קליטת ליד | **Zapier** (טופס Meta → Arbox). **הוחלט — לא בוט, לא דף נחיתה.** ~$25/חודש | ✅ חי, טופס פעיל 1542048374099477 (עודכן 9/6) |

| 5 | CAPI (לקוחה→מטא) | מנוי חדש ב-Arbox → Purchase לפיקסל 1016773848190436 | ✅ LIVE, `test_mode=false` מ-7/6 (עודכן 9/6) |
| 6 | מדידה ₪/לקוחה פר-קמפיין | `compute_conversion_by_source` (מאיה) → דוח שבועי/חודשי | ✅ פרוס |

## 🔒 החלטות נעולות
- **קליטת ליד = Zapier.** מסלולי בוט-מושך-לידים (`meta_leads.py`/`leads_intake.py`) + דף-נחיתה = **נטושים, כבוי-בטוח בקוד.** חסם הבוט: מטא דורשת `leads_retrieval` = App Review (לא שווה את המאמק כרגע). מסלול חינם עתידי בלבד = App Review.
- **CAPI חי (עודכן 9/6): `test_mode=false` כבר מופעל מ-7/6, deployed.** ההחלטה ההיסטורית הייתה flip רק עם קמפיין; בפועל ה-CAPI כבר LIVE. מטא לומדת כשרצים מודעות שהלקוחה ראתה.
- **שום כסף בלי go.** flip ל-CAPI חי / השקת תקציב / חיבור קמפיין אמיתי = רק "כן" מפורש של אור.

## הקוד (steps-brain, Railway)
- CAPI: `app/integrations/meta_capi.py` + `app/triggers/capi_sync.py`. דגלים: `CAPI_ENABLED`(true), `CAPI_TEST_MODE`(**false — LIVE, עודכן 9/6**), `META_CAPI_TOKEN`. watermark מונע הצפת-היסטוריה, dedup `arbox_membership_{id}`.
- מדידה: `app/agents/leads.py` → `compute_conversion_by_source(leads, memberships)` — הצלבת טלפון, פר lead_source. אומת חי: Instagram 18%, פייסבוק-ממומן 13%, Facebook גנרי 2%.
- deploy: `cd steps-brain; railway up --service steps-brain-bot --detach` (CLI מחובר). Railway API מתנדנד לפעמים — נסה שוב.
- ⚠️ סוד (`META_*_TOKEN`) ב-Railway = **אור מגדיר ב-dashboard** (CLI חסום למניעת דליפה). דגלים לא-סוד = CLI מותר.

## רצף השקת קמפיין חדש (תחנה 1→2→go)
1. `steps-ad-copy` (זווית מאור) + `steps-image-gen` (קריאייטיב/קרוסלה) → אישור אור.
2. טופס Instant Form על הקמפיין + חבר את ה-Zap לטופס הפעיל 1542048374099477 (עודכן 9/6; הישן/מושבת 932183859855315).
3. **ליד-בדיקה אמיתי** (שער): Arbox מתויג + משימה + וואטסאפ. רק כשעובד →
4. CAPI כבר חי (`test_mode=false` מ-7/6) → נשאר רק השקת תקציב — **go של אור** (עודכן 9/6).
5. מדידה רצה אוטומטית (תחנה 6) → דוח ₪/לקוחה פר-קמפיין.

## אנטי-סלט (לקח 4/6)
אור התבלבל מ-3 מסלולי-קליטה מתחרים. **תחנה 2 נעולה = Zapier.** אל תציע מסלולים חלופיים אלא אם אור מבקש לחסוך — ואז רק App Review.
