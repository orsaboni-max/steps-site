# Lead Pipeline Build Spec
עודכן: 2026-05-28

## מטרה
לבנות צינור לידים אמין שבו אין ליד שנשאר בלי טיפול, וכל ליד ניתן למדידה עד שיעור היכרות/מנוי.

## מה כבר ידוע

### Meta
חשבון מודעות:
`act_9773300439396945`

קמפיין פעיל עיקרי:
`סניף פולג 18.11.25`
`120234072260610590`

שני הטפסים הפעילים המרכזיים:

- `1295250332452206` על דף `100998226019465`
- `24484335131190836` על דף `815909245241691`

ב-30 יום, 7 מודעות פעילות בקמפיין יצרו 39 לידים.

### Arbox
Arbox מקבל לידים עם מקור כללי כמו `Facebook`, אבל לא מחזיר בשדות הגלויים:

- campaign id
- ad set id
- ad id
- form id
- UTM

כל 39 הלידים ממקור Facebook בסטטוס `Not Contacted` הם בלי אחראי טיפול.

### Make
לפי תיעוד קלוד, תרחיש Make ללכידת Lead Ads היה כבוי.
לפי דף האינטגרציה הרשמי של Make ל-Arbox, Make תומך בפעולות:

- Create a Lead
- Create a Task
- Book to a Trial Class
- Make an API Call

מקור:
https://www.make.com/en/integrations/arbox

## החלטה שצריך לקבל לפני בנייה
צריך לבחור מי הוא "השער הראשי" של ליד חדש:

### אפשרות A: Upgrade 360 נשאר השער הראשי
המסלול:
Meta Form -> Upgrade 360 -> Arbox Lead + WhatsApp

מה צריך לתקן:
- Upgrade 360 חייב להגדיר אחראי טיפול בארבוקס.
- Upgrade 360 חייב להחליף סטטוס מ-Not Contacted ל-WhatsApp sent או סטטוס מקביל.
- אם אפשר, Upgrade 360 צריך לשמור form/campaign/ad metadata בשדה הערה/תגית/שדה מותאם.
- Make נשאר למדידת המרות ודוחות.

יתרון:
פחות סיכון לשבור משהו שכבר עובד.

חיסרון:
אם Upgrade לא מאפשר metadata ו-task routing טוב, המדידה תישאר חלשה.

### אפשרות B: Make הופך לשער הראשי
המסלול:
Meta Form -> Make -> Arbox Create Lead -> Arbox Create Task -> Upgrade 360 WhatsApp -> Meta CAPI

מה צריך לבנות:
- Facebook Lead Ads trigger לכל הטפסים הפעילים.
- Deduplication לפי טלפון כדי לא ליצור כפילויות.
- Create Lead בארבוקס עם מקור, מוצר, סטטוס ואחראי.
- Create Task בארבוקס לאחראית.
- שליחת WhatsApp דרך Upgrade 360 או API/וובהוק מתאים.
- שליחת אירוע conversion חזרה ל-Meta אחרי Trial/Membership.

יתרון:
שליטה מלאה במדידה, שיוך, סטטוסים ומשימות.

חיסרון:
יותר רגיש. אסור להפעיל לפני בדיקת ליד מלאה, כדי לא לשבור את הצינור הקיים או ליצור כפילויות.

## המלצה כרגע
להתחיל באפשרות A כשלב ראשון:

1. לא לשנות את מסלול הלידים הקיים.
2. לבדוק ב-Upgrade 360 האם אפשר להוסיף אחראי/סטטוס/משימה/metadata.
3. אם Upgrade מוגבל, לבנות את אפשרות B ב-Make במצב בדיקה בלבד.

## בדיקת ליד חובה
לפני הפעלה:

1. ליצור ליד בדיקה מטופס אחד בלבד.
2. לוודא שהוא נכנס לארבוקס פעם אחת בלבד.
3. לוודא שיש לו אחראי טיפול.
4. לוודא שנפתח סטטוס נכון.
5. לוודא שנשלחה הודעת WhatsApp.
6. לוודא שאין כפילות באותו מספר.
7. לוודא שאפשר לראות בדוח מאיזה טופס/קמפיין הוא הגיע.

## מה לא עושים עכשיו
- לא משנים תקציב.
- לא מכבים את קמפיין הסוכנות.
- לא מפעילים תרחיש Make ישן בלי להבין מה הוא עושה.
- לא שולחים הודעות WhatsApp ללקוחות אמיתיים לבדיקה.
- לא יוצרים לידים אמיתיים כפולים בארבוקס.
