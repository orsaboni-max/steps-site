# מפרט השקה Meta — STEPS (טורנקי)
> נבנה 2026-05-23 | מלווה את campaign-brief.md. מטרה: שברגע שיש תקציב+חשבון+קריאייטיב — ההעלאה לאוויר מכנית.

## מבנה הקמפיין
```
Campaign: STEPS_Leads_רכישה_2026Q2
  Objective: Leads (Click-to-WhatsApp)   ← תואם CTA המנצח מקומית
  Budget: CBO (תקציב ברמת קמפיין)   ← [תקציב חודשי / 30 = יומי]

  Ad Set 1: קהל_קר_נתניה
    Geo: נתניה + 12 ק"מ | נשים | 25–55
    Interests: כושר, פילאטיס, אורח חיים בריא, אמהות
  Ad Set 2: Lookalike_מתאמנות
    Source: Custom Audience מ-530 מתאמנות (העלאה מ-Arbox), 1–3%
  Ad Set 3: ריטרגטינג
    Source: מבקרי אתר (Pixel) + מעורבות IG/FB 365 יום

  בכל Ad Set: 3 מודעות = זווית A / B / C (מ-campaign-brief.md)
```

## הגדרות מומלצות
- **אופטימיזציה:** Conversations / Leads. אירוע: שיחת WhatsApp נפתחה.
- **Placements:** Advantage+ (אוטומטי) — פיד IG+FB, Reels, Stories.
- **תקציב התחלתי מוצע (70/20/10):** 70% קר, 20% Lookalike, 10% ריטרגטינג. (אם תקציב <2,000₪ — להתחיל רק קר + ריטרגטינג.)
- **לוח זמנים:** רצוף, עם בדיקת ביצועים אחרי 4–5 ימים (יציאה מ-learning phase).

## העלאת Custom Audience מ-Arbox (ל-Lookalike)
1. אייצא רשימת 530 מתאמנות מ-Arbox (טלפון/אימייל מוצפנים).
2. אעלה כ-Customer List Custom Audience ב-Meta.
3. אבנה Lookalike 1–3% (ישראל).
   *דורש: גישת אדמין לחשבון Meta + אישורך לשימוש בדאטה (תואם מדיניות).* 

## נכסי קריאייטיב נדרשים (per זווית)
- 1 רילז/וידאו 9:16, 15–30ש' (סטודיו, מאמנות, אווירה).
- 1–2 תמונות 1:1 ו-4:5.
- מהמאגר הקיים: `images/` (gym-card, move-card, pilates-card, gallery-*). חסר: וידאו אנכי טרי.
